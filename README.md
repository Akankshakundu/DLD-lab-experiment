# Digital Logic Design Laboratory Experiments

This repository contains all DLD lab experiments including:

- Logic Gates
- Adders and Subtractors
- Code Converters
- Multiplexers & Demultiplexers
- Encoders
- Flip-Flops
- Counters

## Tools Used
- Logisim Evolution
- Tinkercad
- Verilog HDL

## List of Experiments

1. Logic Gates Truth Table
2. NAND/NOR Realization
3. Half & Full Adder/Subtractor
4. 4-bit Ripple Carry Adder
5. BCD to Excess-3
6. Excess-3 to BCD
7. Binary to Gray
8. Gray to Binary
9. Seven Segment Display
10. 2x1 Multiplexer
11. 8x1 Multiplexer
12. 8x1 using 2x1
13. Demultiplexer
14. Encoder
15. Priority Encoder
16. Comparator
17. Parity Generator & Checker
